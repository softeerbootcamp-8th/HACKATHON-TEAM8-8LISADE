## 2026-08-26 — 교사 화면 로딩·전환·반응형 UI 개선 (#225)

- 홈·학생·미션·관리 목록의 최초 조회에 접근 가능한 공통 `ListSkeleton`을 적용했다.
- 홈의 확인 필요 학생과 미션 목록 제목 아래 간격을 학생 탭과 같은 12px로 맞췄다.
- 현장체험학습 생성·상세 상단바는 하단 1px 선만 유지하도록 수정했다.
- 탭 콘텐츠에 160ms 진입 애니메이션을 적용하고 동작 줄이기 설정에서는 제거했으며, 선택 탭 배경을 `#FFC93D`로 변경했다.
- 440px 앱 화면 바깥의 데스크탑 캔버스는 흰색으로 분리했다.

검증:

- `npm test -- --configLoader runner`: 42개 파일, 289개 테스트 통과
- `npm run lint`: 오류 0개, 기존 Fast Refresh 경고 3개
- 앱·Vite 설정 TypeScript 검사와 `vite build --configLoader runner`: 통과
- Browser 플러그인으로 320×568, 360×800, 390×844, 430×932에서 가로 넘침·컨트롤 잘림 없음 확인
- 1440×900에서 앱 본문 440px, 흰색 양옆 배경, 콘솔 경고·오류 없음 확인
