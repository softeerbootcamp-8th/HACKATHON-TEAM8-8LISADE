# Trip

## Issue #42 — 카카오맵 지오펜스 기반 현장체험학습 생성

- 관리 탭에서 2단계 등록 화면으로 진입해 제목, 일자, 장소를 입력하고 지오펜스를 지정한다.
- Kakao Maps JavaScript SDK의 키워드 검색 결과를 장소명과 주소 목록으로 표시하고, 사용자가 선택한 위치로 지도 중심만 이동하며 검색 마커는 만들지 않는다.
- 지도 클릭 좌표가 3개 이상이면 초록색 점선 다각형을 표시하고, 지도 우측 하단 버튼으로 마지막 좌표를 제거한다.
- 생성 직전에 Turf로 다각형을 바깥쪽 20m 확장하고 좌표를 소수점 7자리로 정규화한다.
- `POST /api/teacher/trips`는 체험학습 정보와 지오펜스 좌표를 함께 받아 같은 트랜잭션에서 지오펜스, 순서가 보존된 좌표, 체험학습을 저장한 뒤 초대 코드를 발급한다.
- JavaScript 키는 `VITE_KAKAO_MAP_APP_KEY`로 주입하며 실제 값은 Git에서 제외된 `frontend/.env.local`에만 둔다. 브라우저에 전달되는 JavaScript 키이므로 Kakao Developers의 허용 도메인 제한을 함께 사용한다.

검증: 프런트엔드 테스트 56개, ESLint, 프로덕션 빌드, 백엔드 Gradle 빌드와 테스트를 통과했다. 허용 도메인과 카카오맵 서비스를 활성화한 뒤 SDK HTTP 200 응답과 실제 지도 렌더링을 확인했다.

## 교사 관리 탭 및 체험학습 목록 조회 (#47)

- `GET /api/teacher/trips`는 로그인한 교사가 만든 Trip만 생성일 역순으로 반환한다. 목록 응답은 `tripId`, `title`, `place`, `startAt`, `status`만 포함한다.
- 로그인·현재 사용자 응답에 교사 연락처를 추가해 관리 탭의 교사 정보가 세션 사용자 데이터로 표시되도록 했다.
- 관리 탭은 API 목록을 날짜·장소·상태 카드로 표시하며 로딩, 오류, 빈 목록을 각각 처리한다. 추가 CTA는 이번 이슈 범위에 맞춰 준비 중 안내만 제공한다.
- Figma `80:531`의 402 × 874 원본 값을 기준으로 카드, 상태 배지와 CTA의 크기·간격을 구현했다. 상세 비교 결과는 루트의 `design-qa.md`에 기록했다.
- 관리 탭도 공통 `AppHeader`와 교사 하단 탭을 재사용하며, 로고·알림·탭 아이콘은 저장소의 Figma 원본 SVG를 사용한다.
